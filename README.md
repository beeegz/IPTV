## What it does

|     |     |
| --- | --- |
| 📺 **Live TV, movies and series** | Imports M3U/M3U8 playlists from a URL or a file, and Xtream Codes accounts. Catalogs with hundreds of thousands of titles stay smooth. |
| 🗓️ **TV guide and catch-up** | XMLTV program grid, what's on now right in your lists, and past shows when your provider supports it. |
| ⬇️ **Downloads** | Keep a movie, an episode or a whole season to watch offline, in the folder of your choice. Downloads resume on their own after a dropped connection. |
| 🔁 **Playback that holds up** | A brief dropout? The stream reconnects by itself and stays in full screen. A channel stuck? The refresh button reopens it without switching away. |
| 📱 **On your phone** | Picture in picture while you use other apps, and a radio mode that keeps the sound playing with the screen locked. |
| 🔎 **Instant search** | Handles accents and typos, with sorting and country filters. |
| ⭐ **Favorites your way** | General favorites, or as many lists as you like, each with its own name, icon and order. |
| ✨ **FILTERED** | Automatically sorts your provider's hundreds of groups by region, country and theme. Your playlists are never changed. |
| 💾 **Backups** | Export your settings and favorites. Passwords are only included in a file encrypted with your passphrase. |
| 🔒 **Signed updates** | The app checks the signature and checksum of each version before installing it. |
| 🌍 **10 languages** | Français, English, Español, Português, Deutsch, Italiano, Русский, Türkçe, Bahasa Indonesia, Tiếng Việt. |

## Installation

All files are on the [releases page](https://github.com/BigFatDeuce/Chud-IPTV/releases/latest).

| Device | File | How to install |
| --- | --- | --- |
| **Windows** 64-bit | `…-windows-x64-setup.exe` | Run it. No administrator rights needed. |
| **Windows** portable | `…-windows-x64.zip` | Unzip it, then run `Chud IPTV.exe`. |
| **Android** (most devices) | `…-arm64.apk` | Open the file and allow installs from this source. |
| **Android** (older devices) | `…-armv7.apk` | Use this one if the `arm64` version won't install. |
| **Linux** | `…-x86_64.AppImage` | `chmod +x Chud-IPTV-*.AppImage`, then run it. |

> [!NOTE]
> The app isn't signed with a paid Windows certificate, so SmartScreen may show a warning the first time.
> Click **More info**, then **Run anyway**.

## Getting started

1. Open the app and choose **Add a source**.
2. Enter your Xtream Codes account or playlist URL, or pick an M3U file.
3. Let the import finish, and you're done. Turn off movies and series for a lighter load.

## Privacy

- No account, no ads, no usage statistics.
- The app only contacts your sources, the logo and guide addresses from your playlists, and GitHub to look for updates. You can
  turn off that automatic check in Settings.
- Your data stays on your device.

## Project status

The current version has been tested on Windows, an Android emulator and a clean Debian 13 install. Testing on real phones and TVs
is still underway, so feedback is welcome in the [issues](https://github.com/BigFatDeuce/Chud-IPTV/issues).

This repository hosts the releases. The source code isn't published here.

Chud IPTV doesn't bypass any DRM. You are responsible for the content you access with the app.
